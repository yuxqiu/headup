# Voice credits

The spoken prompts in this directory were generated with [Piper](https://github.com/rhasspy/piper) using
the `en_GB-alba-medium` voice from [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices).

- Voice dataset: "alba", University of Edinburgh DataShare, https://datashare.ed.ac.uk/handle/10283/3270,
  licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- The voice model was fine-tuned from Piper's `hifi_tts_92` base model, trained on the Hi-Fi TTS
  dataset. That dataset's license is believed to be CC BY 4.0 `[unverified]`.

To regenerate the clips, run `tools/gen_voice.sh`.
